# Bali Express Video Maker

Jalankan lokal (disarankan): klik dua kali `start.bat`. Browser terbuka ke http://localhost:3000.
Render memakai ffmpeg asli di komputer ini. Taruh `ffmpeg.exe` di folder `bin\` kalau ffmpeg belum ada di PATH.
Tanpa server lokal (misalnya di Vercel), app otomatis memakai ffmpeg.wasm di browser (lebih lambat).
